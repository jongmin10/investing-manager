# Agent List — 퇴직연금 경제지표 대시보드 개발

**버전** 0.1 | **작성일** 2026-06-17

---

## 1. 전체 구성

```
         Agent 0 (PM) ← 전체 총괄
              ↓
    Agent 1 (DB/스키마)
              ↓
Agent 2 (데이터 수집) ──→ Agent 3 (백엔드 API)
                                ↓
                  Agent 4 (UI) + Agent 5 (차트)
                                ↓
                         Agent 6 (인증)
                                ↓
                  Agent 7 (테스트) → Agent 8 (배포)
```

---

## 2. Agent 상세

### Agent 0 — PM (Project Manager)

전체 개발 흐름을 총괄하고 Agent 간 의존 관계를 조율한다.

**주요 역할**
- **작업 분배**: Phase별 우선순위에 따라 각 Agent에 태스크 할당
- **의존성 관리**: Agent 1 완료 전 Agent 2·3 시작 차단 등 순서 강제
- **진행 상황 추적**: 각 Agent의 완료 여부 확인, 블로커 감지
- **품질 게이트**: Phase 전환 전 체크리스트 검증 (예: Phase 1 완료 기준 충족 확인)
- **문서 관리**: `docs/` 폴더 최신 상태 유지, 변경사항 반영
- **이슈 조율**: Agent 간 인터페이스 불일치(API 스펙, DB 스키마 변경 등) 발생 시 중재

**운영 방식**

각 개발 세션 시작 시 PM Agent가 먼저 실행되어 현재 상태를 파악하고 다음 실행할 Agent와 태스크를 지정한다. Claude Code의 Task 기능과 연계하여 진행 상황을 추적한다.

---

### Agent 1 — DB/스키마 설계

Prisma 스키마 정의, 마이그레이션 관리, 테이블 설계를 전담한다. 다른 Agent들이 참조할 데이터 구조의 기준을 잡기 때문에 가장 먼저 실행한다.

**담당**
- 사용자 테이블, 설문 결과, 알림 설정, 지표 캐시 테이블 설계
- Prisma 마이그레이션 파일 관리
- 초기 시드 데이터 작성

**선행 조건**: 없음 (최초 실행)

---

### Agent 2 — 데이터 수집기

외부 API 연동과 스케줄러를 담당한다. 각 API의 인증, 호출 주기, 에러 핸들링을 처리한다.

**담당**
- 10개 지표별 외부 API 연동 (한국은행, 통계청, KRX, CBOE 등)
- node-cron 스케줄 설정
- Redis TTL 캐싱 로직
- API 호출 실패 시 재시도 및 알림 처리

**선행 조건**: Agent 1 완료 (DB 스키마 확정)

---

### Agent 3 — 백엔드 API

Next.js API Routes로 프론트엔드가 호출할 내부 API 엔드포인트를 구현한다.

**담당**
- 지표 조회 API
- 성향 설문 저장/조회 API
- 알림 설정 API
- 포트폴리오 계산 로직
- API 응답 스펙 문서화

**선행 조건**: Agent 1 완료 / Agent 2와 병렬 진행 가능

---

### Agent 4 — 프론트엔드 UI

페이지 레이아웃, 컴포넌트 구조, 반응형 디자인을 담당한다.

**담당**
- 대시보드 레이아웃
- 지표 카드 컴포넌트
- 성향 설문 UI
- 경제 캘린더 페이지
- 모바일/태블릿/PC 반응형 처리

**선행 조건**: Agent 3 API 스펙 확정 후 진행 (Agent 5와 병렬 가능)

---

### Agent 5 — 차트/시각화

Recharts 기반 차트 컴포넌트를 전담한다. 데이터 형식 변환과 차트 옵션 최적화를 포함한다.

**담당**
- 지표 추세 라인 차트
- 자산 배분 파이 차트
- 수익률 비교 차트
- 이상 신호 하이라이트 시각화

**선행 조건**: Agent 3 API 스펙 확정 후 진행 (Agent 4와 병렬 가능)

---

### Agent 6 — 인증

NextAuth.js 설정과 Phase 2 로그인 기능을 담당한다.

**담당**
- 소셜 로그인 연동 (Google / 카카오)
- 세션 관리
- 인증 미들웨어 (보호 라우트 처리)
- 회원가입/탈퇴 플로우

**선행 조건**: Agent 4 UI 기본 구조 완료 후 진행

---

### Agent 7 — 테스트/QA

단위 테스트와 통합 테스트 작성을 전담한다.

**담당**
- API 엔드포인트 단위 테스트
- React 컴포넌트 테스트
- 데이터 수집기 테스트
- Phase 전환 전 회귀 테스트 실행

**선행 조건**: 각 Phase 기능 완료 후 실행

---

### Agent 8 — 배포/인프라

Vercel·Supabase·Upstash 환경 설정과 CI/CD 파이프라인을 담당한다.

**담당**
- 환경변수 관리 (.env 구성)
- GitHub Actions CI/CD 설정
- Vercel 배포 설정
- Supabase 프로덕션 DB 마이그레이션
- 모니터링 설정

**선행 조건**: Agent 7 테스트 통과 후 실행
