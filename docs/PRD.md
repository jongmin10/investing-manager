# PRD — 퇴직연금 경제지표 대시보드 웹서비스

**버전** 0.2 | **작성일** 2026-06-17

---

## 1. 배경 및 목적

퇴직연금(DC/IRP) 가입자는 스스로 운용 지시를 해야 하지만, 분산된 경제 정보를 직접 취합하기 어렵다. 본 서비스는 퇴직연금 관리에 필요한 핵심 경제지표를 한 곳에 모아 제공하고, 투자자 성향 기반 포트폴리오를 제안함으로써 비전문 직장인도 체계적인 자산관리를 할 수 있도록 지원한다.

---

## 2. 목표 사용자

일반 직장인 DC/IRP 가입자로, 경제 지식이 깊지 않고 별도 자문 없이 스스로 운용 지시를 내리는 사람.

---

## 3. 개발 단계

### Phase 1 — 핵심 대시보드 (MVP)

**목표:** 경제지표를 한눈에 볼 수 있는 기본 대시보드 구축

#### 3.1.1 경제지표 대시보드

10개 지표를 카드 형태로 시각화한다. 각 카드는 현재값, 전월 대비 변동, 추세 차트(6개월~1년)를 표시한다.

| # | 지표 | 데이터 소스 | 업데이트 주기 |
|---|------|------------|--------------|
| 1 | 한국은행 기준금리 | 한국은행 Open API | 금통위 결정 시 |
| 2 | 국고채 금리 (3Y/10Y) | 금융투자협회 | 매 영업일 |
| 3 | KOSPI / KOSDAQ | KRX | 실시간 |
| 4 | S&P 500 | 공개 주식 API | 실시간 |
| 5 | 소비자물가지수 (CPI) | 통계청 | 월 1회 |
| 6 | 생산자물가지수 (PPI) | 통계청 | 월 1회 |
| 7 | 원/달러 환율 | 서울외국환중개 | 실시간 |
| 8 | 경기선행지수 (CLI) | 통계청 / OECD | 월 1회 |
| 9 | 실업률 | 통계청 | 월 1회 |
| 10 | VIX (공포지수) | CBOE / 금융 API | 실시간 |

**요구사항**
- 지표별 "이게 왜 중요한가" 한 줄 설명 툴팁 제공
- 이상 신호 발생 시 하이라이트 표시 (예: VIX 30 초과, CPI 3% 초과)
- 기간 선택 필터 (1개월 / 3개월 / 1년 / 3년)
- 로그인 없이 대시보드 조회 가능

#### 3.1.2 경제 용어 사전

비전문가 대상 서비스이므로 CPI, VIX 등 용어를 쉽게 설명하는 인앱 사전.

**요구사항**
- 지표 카드에서 용어 클릭 시 팝업으로 설명 표시
- 별도 용어 사전 페이지에서 전체 용어 목록 조회 가능

---

### Phase 2 — 투자자 성향 기반 포트폴리오 제안

**목표:** 사용자 맞춤 자산 배분 추천 기능 추가 (로그인 필요)

#### 3.2.1 성향 진단 설문

**흐름**

1. 성향 진단 설문 (5~7문항) — 투자 목적, 투자 가능 기간, 손실 허용 범위, 퇴직까지 남은 연수
2. 성향 분류 — 안정형 / 안정추구형 / 위험중립형 / 적극투자형 / 공격투자형
3. 현재 경제지표 상태와 결합하여 자산 배분 비율 제안
4. 추천 상품 유형 안내 (원리금보장 / 채권형 / 혼합형 / 주식형 비율)

**요구사항**
- 설문 결과 저장 및 재진단 기능
- "현재 시장 환경 반영" 문구로 지표 연계성 명시
- 투자 조언이 아닌 정보 제공임을 고지하는 면책 문구 필수

#### 3.2.2 포트폴리오 리밸런싱 신호

현재 시장 지표와 사용자 성향을 비교해 "리밸런싱 고려 시점" 신호를 제공한다.

**요구사항**
- 시장 이벤트 기반 신호 생성 (예: VIX 급등 + 주가 10% 하락 → "안전자산 비중 확대 검토")
- 성향별 신호 임계값 차별화 (안정형은 민감하게, 공격투자형은 느슨하게)
- 신호 이력 조회 가능

---

### Phase 3 — 알림 및 개인화

**목표:** 사용자가 서비스를 능동적으로 활용하도록 알림·개인화 기능 추가

#### 3.3.1 지표 알림 설정

사용자가 특정 지표에 임계값을 설정하면 웹 푸시 또는 이메일로 알림 발송.

**요구사항**
- 지표별 임계값 직접 설정 (예: 기준금리 0.25% 이상 변동 시 알림)
- 알림 채널 선택: 웹 푸시 / 이메일
- 알림 수신 이력 조회

#### 3.3.2 경제 캘린더

향후 주요 경제 이벤트 일정을 제공한다.

**요구사항**
- 금통위 회의, 미 FOMC, 고용지표·물가지표 발표일 표시
- 이벤트 D-Day 카운트다운
- 관심 이벤트 즐겨찾기 및 알림 연동

#### 3.3.3 나의 수익률 트래커

사용자가 현재 퇴직연금 운용 현황을 입력하면 시장 지표 대비 성과를 비교한다.

**요구사항**
- 펀드명, 편입 비중, 최초 매수 시점 수동 입력
- 입력한 포트폴리오의 추정 수익률 계산 및 표시
- 벤치마크(KOSPI, 물가상승률 등)와 비교 차트 제공
- 실제 계좌 연동 없이 수동 입력 방식으로 구현

## 4. 비기능 요구사항

| 항목 | 요구사항 |
|------|---------|
| 반응형 | 모바일 / 태블릿 / PC 모두 지원 |
| 데이터 갱신 | 실시간 지표는 최대 15분 지연 허용 |
| 면책 고지 | 모든 페이지에 "투자 참고용 정보이며 투자 결과에 책임지지 않음" 표시 |
| 인증 | Phase 1은 비로그인, Phase 2부터 회원가입/로그인 필요 |

---

## 5. 단계별 요약

| Phase | 주요 기능 | 비고 |
|-------|----------|------|
| **Phase 1** | 경제지표 대시보드, 경제 용어 사전 | 비로그인 서비스, MVP |
| **Phase 2** | 투자자 성향 진단, 포트폴리오 제안, 리밸런싱 신호 | 로그인 필요 |
| **Phase 3** | 지표 알림, 경제 캘린더, 수익률 트래커 | 개인화 고도화 |
