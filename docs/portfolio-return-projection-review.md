# 포트폴리오 수익률 프로젝션 기간 정책 — 재검토

> 상태: **검토(설계) · 구현 대기** · 작성 2026-07-03
> 배경: KODEX 200(KOSPI200) 수익률이 비정상으로 높게 표시됨(CAGR ~56%). 원인 분석 결과 **3년 단기 이력만으로 산출한 CAGR를 30년까지 복리 투영**하는 구조가 문제. "가용한 전체 기간의 수익률"을 쓰도록 재검토한다.
> ⚠️ 이 문서는 설계 검토이며 **코드 변경은 포함하지 않는다(구현은 추후)**.

---

## 1. 문제 정의

투자전략 플래너의 수익률 분석은 각 ETF의 CAGR을 1/3/5/10/20/30년으로 복리 투영한다.
- 프로젝션 = `(1 + CAGR)^년수 − 1`
- KODEX 200의 CAGR가 ~56%이면 30년 투영 시 `(1.56)^30 ≈ 수십만 배` → 비현실적 숫자.

## 2. 현재 동작 (코드 확인 결과)

- **recalc(`scripts/recalc-etf-returns.mjs`)는 이미 "가용 이력의 전체 span"을 사용한다.**
  - `years = (last − first) / 365.25` (고정 3년 창이 아님). CAGR도 이 span 기준.
- **문제는 이력 자체가 3년치뿐이라는 점.**
  - `scripts/backfill-index-history.ts`가 Yahoo chart API를 **`range=3y`로 하드코딩**(라인 53).
  - 그 결과 IndicatorRecord의 KOSPI200/SP500/NASDAQ100/KRW_USD 이력이 모두 2023-06~ (약 3년).
- 최근 3년(2023~2026)이 이례적 강세장이라 3년 CAGR가 과대(KOSPI200 ~56%).

> 즉 **recalc 로직은 이미 "전체 기간"을 쓰도록 되어 있고, 정작 "전체 기간"이 3년으로 잘려 있는 것이 근본 원인.** 레버는 recalc가 아니라 **백필 범위 확장 + 기간 정책 확정**.

## 3. 정량 근거 (Yahoo 실측, 읽기 전용 조회)

동일 지수를 창 길이만 달리해 산출한 CAGR:

| 지수 | 3년 CAGR | 10년 CAGR | 20년 CAGR |
|------|:-------:|:--------:|:--------:|
| KOSPI200 (`^KS200`, 1996~) | **54.5%** | 17.8% | **10.7%** |
| S&P500 (`^GSPC`, USD) | 17.8% | 13.1% | 9.1% |
| NASDAQ100 (`^NDX`, USD) | 25.8% | 19.6% | 15.5% |
| KRW/USD (`KRW=X`, 2003~) | 6.4% | ⚠️ 158.6% | 2.5% |

- 3년→20년으로 창을 넓히면 KOSPI200 CAGR가 **54.5% → 10.7%** 로 정상화(장기 기대수익 수준).
- 30년 투영 결과도 `(1.107)^30 ≈ 21배`로 현실적 범위.

## 4. 권장 방향

**A. 백필 범위를 장기(15~20년)로 확장하고, recalc가 그 전체 span으로 CAGR을 산출하게 한다.**
- `backfill-index-history.ts`의 `range=3y` → 장기(예: `range=20y` 또는 `max`, 또는 `period1/period2`)로 변경.
- recalc 로직은 그대로(이미 전체 span 사용) — 데이터만 길어지면 자동 반영.
- `interval`은 장기엔 일봉이 과다하므로 주봉/월봉 검토(정밀도 vs 용량).

**B. 대표 기간(lookback)을 통일한다.**
- 지수별 상장 시점이 달라 "가용 최대"가 제각각(KOSPI200 1996~, KRW=X 2003~).
- 항목 간 CAGR 비교 일관성을 위해 **공통 lookback(예: 15년 또는 20년)** 을 정하고 그 창으로 산출 권장.
- MANUAL 항목(국채·TDF·혼합국채)도 같은 관점에서 기간 표기 재정렬 검토.

## 5. 트레이드오프·주의사항 (구현 시 반드시 반영)

1. **FX 데이터 글리치**: `KRW=X` 월봉 10년 구간에 이상치(CAGR 158.6%, 누적 134만%)가 있음 → 잘못된 틱. **해외 ETF의 원화 환산에 직접 영향.** 백필/수집 시 **이상치 검증·제거(스파이크 필터)** 필수.
2. **FX 가용 범위 제약**: `KRW=X`는 2003년~만 제공 → 해외 ETF(원화환산)의 "전체 기간"은 **FX 가용범위(~22년)에 의해 상한**. 지수는 더 길어도 FX 겹치는 구간까지만 사용.
3. **국내 데이터 품질(별건)**: 현 DB의 KOSPI200이 KOSPI 대비 상방 드리프트(비율 0.132→0.159). 장기 이력은 최근 왜곡의 영향을 희석하지만 **끝점 왜곡 자체는 별도로 조사·정정** 필요.
4. **해외 ETF 철학**: KODEX S&P500/나스닥100(국내 상장, 설정 2020~2021)에 지수-1996 이력을 쓰면 "존재하지 않던 펀드"의 프록시. 장기 기대수익 관점에선 지수 기반이 타당하나 **"지수 프록시"임을 명시** 필요(설정이후 실적과 구분).
5. **일봉 용량**: 20년 일봉 × 다지수 = 수만 행. 월/주봉 다운샘플 권장(프로젝션 CAGR엔 충분).
6. **daily cron 무영향**: 백필은 1회성 재구축(deleteMany+재삽입). 일일 수집은 1점/일 append로 별개 → 안전.

## 6. 예상 영향 (20년 창 적용 시)

| ETF | 현재(3년) CAGR | 20년 창 CAGR(추정) |
|-----|:---:|:---:|
| KODEX 200 | ~56% | ~11% |
| KODEX S&P500 | ~26% | ~9%(USD)+FX |
| KODEX 나스닥100 | ~33% | ~15.5%(USD)+FX |

→ 30년 프로젝션이 "수만 배"에서 "십수~수십 배"의 현실적 범위로 정상화. 모바일 숫자 중첩(UI)도 부수적으로 완화(단, UI는 PR #41에서 이미 큰 값 안전 처리).

## 7. 미결정 사항 (구현 착수 전 확정)

1. **공통 lookback**: 15년 vs 20년 vs "가용 최대"(항목별 상이 허용).
2. **interval**: 월봉 vs 주봉 (용량·정밀도).
3. **FX 이상치 필터 기준**: 전월 대비 ±N% 초과 제거 등 구체 규칙.
4. **MANUAL 항목 재정렬 여부**: 채권·TDF도 동일 기간 관점으로 통일할지.
5. **해외 ETF 기준**: 지수 프록시(장기) vs 설정이후(실적). 표기 방식.
6. **KOSPI200 끝점 드리프트**(별건) 조사·정정 선행 여부.

## 8. 결론

- recalc는 이미 전체 span을 쓰므로 **로직 결함이 아니라 "가용 이력이 3년으로 잘려 있는 데이터 범위" 문제**.
- **핵심 조치 = 백필 `range` 확장(장기) + 공통 lookback 확정 + FX 이상치 필터.**
- 정량적으로 20년 창 적용 시 KOSPI200 CAGR ~56%→~11%로 정상화됨을 실측으로 확인.

### 9.1 확정 파라미터
- **대상 지수**: `KOSPI200(^KS200)`, `SP500(^GSPC)`, `NASDAQ100(^NDX)`, `KRW_USD(KRW=X)`
- **백필**: `interval=1mo`, 기간 = 최근 **22년**(20년 창 + FX 매칭 버퍼 2년). Yahoo `period1/period2` 사용(`range=3y` 대체).
- **recalc 변경(최소)**: "전체 span" → **롤링 20년 창**. 기준점 = `last − 20년`에 가장 가까운 포인트. 가용 <20년이면 가용 최대 사용하되 **<10년이면 저신뢰 플래그**.
- **FX 필터**: 백필·daily 수집 공통 적용(§9 #3 규칙).
- **해외 환산**: 20년 지수 × 동일 구간 FX. FX 가용범위(2003~)가 상한이면 그 구간까지만.

### 9.2 예상 결과 (실측 기반)
| ETF | 현재(3년) | 제안(20년) |
|-----|:---:|:---:|
| KODEX 200 | ~56% | **~11%** |
| KODEX S&P500 | ~26% | ~9%(USD)+FX ≈ **~11%** |
| KODEX 나스닥100 | ~33% | ~15.5%(USD)+FX ≈ **~18%** |
| 채권·TDF(MANUAL) | 2.5~7.3% | 유지 |

→ 30년 투영: KOSPI200 `(1.11)^30 ≈ 23배`로 현실화. UI 중첩(별건, PR #41에서 안전처리 완료)도 근본 완화.

### 9.3 구현 순서 (착수 시)
1. **backfill**: `range=3y` → `period1/period2`(22년) + `interval=1mo` + FX 필터. 4개 지수 재백필(멱등).
2. **daily collector**: FX 이상치 필터 추가, KOSPI200 소스 감사.
3. **recalc**: 롤링 20년 창으로 변경 → `--apply` 반영.
4. **검증**: 재산출 CAGR가 §9.2 근사인지, 30년 투영이 현실 범위인지 확인.

> 위 세트로 진행 승인 시 구현 착수. 특정 항목만 조정(예: lookback 15년)도 가능.
